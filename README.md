# BridgeAU AI

BridgeAU AI is a hackathon MVP that helps international students and skilled migrants translate their skills and experience into Australian job-market language.

## What it does
- Analyze CV text against an Australian job description
- Identify strengths, transferable skills, and missing skills
- Rewrite resume summary in a more locally relevant way
- Rewrite resume bullet points
- Generate likely interview questions
- Create a 30-day action plan
- Show responsible AI notes

## Tech Stack
- Next.js 14
- React
- Tailwind CSS
- OpenAI API
- Mock mode supported for stable demos
